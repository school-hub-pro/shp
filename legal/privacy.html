Privacy Policy

Last updated: 14 October 2026

1. About this project

School Hub Pro is an independently developed study tool. It is not a commercial product and is not affiliated with any school, company, or organisation. Anyone can create an account and use the app for free.

2. How this app runs

School Hub Pro is made of three parts that work together. Understanding what each one does is the best way to see that nothing shady is happening.

Part 1 — The page you see (the frontend)
This is the HTML, CSS, and JavaScript that loads in your browser. It is hosted on Cloudflare Pages, a free static-hosting service from Cloudflare. It does not run any code on Cloudflare's servers — Cloudflare only delivers the files to your browser, the same way a web server delivers an image. You can read every line of this code on the public GitHub repository linked in the app's footer.

Part 2 — The app logic (the backend)
When you sign in, save a grade, add a deadline, or do anything else, your browser sends that request to a Google Apps Script backend. Apps Script is a scripting service run by Google. The code that lives there was written by the developer, is stored in the developer's own Google account, and is never visible to your browser. It runs on Google's servers, not on your device.

Part 3 — Where the data lives (the database)
Everything you enter is stored in a single private Google Sheet owned by the developer. Only the developer can open that sheet. The backend reads from it and writes to it on your behalf. Nothing is stored anywhere else.

How your sign-in actually works
When you type your password, the app hashes it right away and sends the hash to the backend. The backend compares it against the hash already stored in the sheet. If they match, the backend sends back a token — a long string of random characters signed with a secret key that only the backend knows. Your browser stores that token and sends it with every request. The token has an expiry date (7 days by default), and it can be cancelled at any time from Settings.

What this means in practice
Because the app is built this way, there are several things it simply cannot do, even if the developer wanted to:

  • It cannot read your passwords. The hash is a one-way function — there is no way to reverse it back to the original password, even with the source code and the database.
  • It cannot access your files, camera, microphone, or location. The browser would ask you for permission first, and School Hub Pro never asks.
  • It cannot see what you do in other tabs. Browsers don't allow that.
  • It cannot send your data to a third party. The only network requests the app makes are to the backend and to two public services (Google Fonts for the font, and the Singapore government weather API for the weather widget). Both are read-only and receive no personal information.
  • It cannot charge you anything. There is no payment system anywhere in the code.

How you can verify this yourself
Every claim in the paragraph above is verifiable from the app itself:

  • Press F12 in your browser to open DevTools. Switch to the Network tab. Everything the app does over the network is listed there in real time. You will see requests to the backend URL, plus the two public services mentioned above, and nothing else.
  • Open the GitHub repository linked in the footer. It contains the exact JavaScript your browser is running, plus the backend code. Read it, fork it, or run it yourself.
  • If you are unsure about any part of the flow, close the tab and do not sign in. Nothing on this page requires you to trust it before you can inspect it.

3. What we collect

When you create an account and use School Hub Pro, the following is stored:

  • Account details — your display name, email address, and a securely hashed copy of your password. The password is never stored in plain text and cannot be read by anyone, including the developer.
  • Content you add — grades, deadlines, personal calendar events, focus sessions, academic goals, and bug reports.
  • Basic usage logs — sign-in times and general actions (e.g. "grades saved"), kept for security and troubleshooting. Passwords and message contents are never logged.

4. What we do NOT collect

No location data, no device identifiers, no browsing history, no analytics, no advertising IDs, and no cookies for tracking. Nothing is collected outside what you enter into the app.

5. Where your data is stored

Data is stored in a private Google Sheets spreadsheet owned by the developer, accessed through a Google Apps Script backend. Access is restricted to the developer. Google's own privacy policy applies to the underlying infrastructure.

6. Who can see your data

  • You — full access to your own data.
  • The developer — can view accounts and content for support, safety, and maintenance.
  • Other users — cannot see your data. The only exception is your display name, and only if you accept a friend request.

Your data is never sold, shared, or transferred to any third party.

7. How long it is kept

Data is kept while your account is active. You can delete your account at any time from Settings → Danger Zone, which permanently removes everything associated with it.

8. Your rights

You can export everything you have added at any time from Settings → Data Export (CSV, JSON, or calendar format). You can request a correction or full deletion by asking the developer directly.

9. Security

Passwords are hashed with PBKDF2-HMAC-SHA256 using per-account salts. Sessions use signed tokens with expiry dates. All traffic is encrypted over HTTPS. No system is perfectly secure, so please use a strong, unique password that you do not reuse elsewhere.

10. Children

School Hub Pro is designed for students and is intended to be used with the knowledge of a parent or guardian. Because it stores only a display name and an email address, it collects no more personal information than is necessary for the app to function.

11. Changes

If this policy changes in a meaningful way, users will be told through the app. Continued use after a change means you accept the updated policy.

12. Contact

For any privacy question or data request, contact the developer directly using the contact link in the app's footer or the email address shown on the GitHub repository.
